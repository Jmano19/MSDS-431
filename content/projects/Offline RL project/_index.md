# Offline Reinforcement Learning Recommendation System

## Overview

A graduate research project evaluating offline reinforcement learning approaches for personalized product recommendation using the Instacart dataset.

## Methods

- Behavioral Cloning
- Naive DQN
- Conservative Q-Learning (CQL)
- Implicit Q-Learning (IQL)
- Advantage-Weighted Actor-Critic (AWAC)
- Markov-based recommendation
- Popularity-based recommendation

## Evaluation

Models were evaluated using:

- Recall@10
- NDCG@10
- HitRate@10
- Precision@10

## Objective

The project investigates how offline reinforcement learning can learn recommendation policies from previously collected user interaction data without requiring online experimentation.
